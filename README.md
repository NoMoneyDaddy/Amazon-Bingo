# 賓果玄學研究台

CubeLV 插件與 Zeabur 後端服務，提供台灣彩券 BINGO BINGO 官方開獎資料同步、可追溯的六套傳統起卦研究模型與歷史勝率統計。

## 目錄

- `frontend/`：CubeLV 插件原始碼
- `service/`：獨立 Node.js API 與 Zeabur Docker 部署檔；插件前端不直接寫入資料

## 後端 API

- `GET /health`：服務健康檢查
- `GET /api/latest`：向台灣彩券官方頁面取得最新開獎資料並產生研究模型

## 本機啟動

```bash
cd service
npm start
curl http://localhost:8080/health
```

服務使用 `PORT` 環境變數，預設為 `8080`；可用 `CORS_ORIGIN` 限制前端來源。

## Zeabur

服務根目錄應指向 `service/`，使用其中的 `Dockerfile` 建置。部署後將公開網址提供給 CubeLV 插件串接。

## 研究邊界

本專案僅供研究與娛樂，不保證中獎、不提供投注或個人化買賣指令。模型採「傳統起卦特徵＋時間衰減歷史頻率＋固定種子排序」：梅花易數使用年月日時起卦，六爻使用六次三枚硬幣的可重現模擬，河圖洛書使用洛書九宮。這些是文化與規則的程式化表達，不是已證實的因果預測；勝率必須以 walk-forward 歷史樣本解讀，且應與公平隨機基線比較。

研究參考：梅花易數的數字／時間起卦傳統、六爻的陰陽與動爻框架、河圖洛書與九宮數理史研究；統計層參考 lotto k/N 超幾何模型的隨機性稽核方法。插件會把每期公式、起卦結果、使用的前期樣本數與自動演化參數一併保存，方便追溯。

自動演化：每次同步會以更早期資料進行 walk-forward 驗證，測試五組歷史頻率權重，並按大小、單雙、超級獎號與各星級分別選擇參數。至少需要 8 期歷史資料；資料不足時使用中性預設值，避免少量樣本過度擬合。
